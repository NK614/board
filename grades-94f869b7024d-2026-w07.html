Refresh button: one-time setup

The button starts Grade picks, then Republish once the grades are done, on GitHub (both free, about 7 minutes), the same as pressing Run workflow there. It needs a key, saved in this browser only.

1. Make a fine-grained GitHub token. Name it "ALP HQ refresh" and pick an expiration.
2. Repository access: Only select repositories → board-builder.
3. Permissions → Repository → Actions: Read and write. Nothing else. Generate, copy it.
4. Paste it here on each device and tap Save. It stays in this browser only and is never synced or published. Once saved, the Key button goes away; if the key ever stops working, this box opens again.

That key can start, re-run or cancel any workflow in board-builder (Build included, which spends credits), but it can't change code, read files or see your other keys.

Each pick is the generator's Best pick for that window, leg count and target, made before the games from the board's prices, and graded with today's generator rules. Hit rates count settled picks only (every leg final); pending ones aren't counted. Money is $10 on each pick at FanDuel's posted price. Break-even is the hit rate those prices needed to make money. The replay lab rebuilds every graded board twice — today's model (champion) and the change (challenger) — and grades both on the same box scores.
